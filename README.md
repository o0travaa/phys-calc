# phys-calc

A practical, lightweight CLI tool written in Go designed to automate routine calculations and handle standard physics formulas quickly, saving you time and effort.

## Features

* **Quick Calculations:** Rapidly evaluate standard physics formulas without manual calculator entries.
* **Go-Powered Performance:** Built using Go for fast compilation and cross-platform execution.
* **Extensible Architecture:** Easily add new formulas and categories inside the modular structure.

## Prerequisites

To run or build this project, you need to have Go installed on your system. 

* [Download and Install Go](https://go.dev) (version 1.16 or higher recommended)

## Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/o0travaa/phys-calc
cd phys-calc
```

## Usage

### Running Directly
You can run the application immediately using the Go toolchain:

```bash
go run main.go
```

### Building the Executable
To compile the project into a standalone binary:

```bash
go build -o phys-calc
```

After building, run the executable:

* **Linux/macOS:** `./phys-calc`
* **Windows:** `phys-calc.exe`
